# Look Here v1.1.0

《非生物因素》UE4SS Lua 多人联机标记 Mod。

- 显示名称：`Look Here`（看这里）
- 内部名称及 Mod 目录：`LookHere`
- 当前版本：`1.1.0`
- 完整版本更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 当前功能

- 鼠标中键或 `Q` 从本地玩家准星方向发起标记，按住 `Ctrl` 或 `Shift` 时仍可触发。
- 聊天框或其他文本输入框获得焦点时，标记按键会被忽略，不消耗冷却。
- 主机自己的标记使用屏幕准星射线；远程玩家使用其同步到服务器的视角。精确命中的实体优先于旁边物体的球形探测结果，每位玩家仍有独立的 3 秒冷却。
- 默认忽略禁建区域，包括工作台附属区域；工作台自身仍可选中。可通过 `IgnoreBuildZones` 切回旧的附属区域处理。
- 命中可见实体时，各客户端沿发送者到命中点的短射线在本地复核对应对象，并对根 Actor 及子 Actor 的真实可见 Mesh 执行一次性描边；普通表面或没有可见 Mesh 的目标使用临时球形锚点。
- 标记文字显示为 `<玩家名> Mark <序号>`，序号最多 8 个并循环回收；颜色按玩家区分。
- 文字和球形标记会在持续时间结束后回收；实体 Mesh 描边只在创建时写入一次，期间不刷新、不轮询。
- `F5` 开关调试模式；仅在调试开启时，`F6` 执行全通道诊断射线并显示简化命中信息，完整内容写入 `UE4SS.log`。
- 多人传输只广播紧凑的目标描述和坐标；每台客户端独立创建文字、球体并解析本地实体，不依赖未复制物体的网络引用。
- v1.1.0 包含性能优化与物体查找、描边修复。

## 已知边界

- 所有参与联机的玩家必须安装相同版本。
- 主机依据玩家同步到服务器的视角重新射线；高延迟时可能与客户端准星命中点略有偏差。
- 本 Mod 针对当前游戏资产与 Pager 函数结构实现；游戏更新后相关路径若发生变化，需要同步适配。
- 使用窄射线本地解析与一次性真实 Mesh 描边；结束时仅恢复仍保持本 Mod 标记状态的 Mesh，已被交互或其他 Mod 改变的状态不处理。

## 安装

主机和每个玩家都要安装：

1. 关闭游戏。
2. 将本压缩包中的 `Binaries` 文件夹复制到游戏的 `AbioticFactor` 子目录中，与现有 `Binaries` 合并。
3. 确认最终存在：
   `AbioticFactor/Binaries/Win64/ue4ss/Mods/LookHere/Scripts/main.lua`
4. 启动游戏并由主机创建多人存档。

本包不会自动修改游戏目录；安装操作由用户手动完成。

## 配置

编辑：

`Binaries/Win64/ue4ss/Mods/LookHere/Scripts/config.lua`

可修改射线距离、球体大小、离开表面的偏移、描边模式、持续时间、冷却、调试文字和调试日志。

## 建议的首次验证顺序

1. 主机与一名客户端都安装本 Mod。
2. 主机按鼠标中键，确认双方是否看到命中点球体描边。
3. 客户端按鼠标中键，确认主机和客户端是否都看到同一标记。
4. 在墙后观察标记，确认穿墙描边。
5. 等待 10 秒，确认球体在双方消失。
6. 检查 `UE4SS.log` 中的 `[LookHere]` 行；若没有球体，把这些日志提供给 Codex。

## 卸载

关闭游戏后删除：

`AbioticFactor/Binaries/Win64/ue4ss/Mods/LookHere`
